## Findings and fixes

### P1 — タイマー設定展開時に時計操作が背後でクリックできない

タイマー設定用dashboardが時計より前面に残り、時計設定ボタンの操作を奪っていた。dashboard wrapperを`pointer-events: none`、内部slotを`pointer-events: auto`に分離し、タイマー設定カードの操作を維持しながら時計操作を通すよう修正した。

### P1 — タイマー設定カードと時計がiPadで重なる

1024×768と768×1024で、中央のタイマー設定カードが左下の時計に重なっていた。iPad向けのタイマー設定位置を上へ調整し、時計との実測矩形が重ならないことを確認した。

### P1 — タスク詳細のクイック設定がモバイルで重なる

期限と集中回数の4ボタンが、CSS Gridの先頭列（約82px）に押し込まれていた。内部ボタン群をクイックグループ全幅へ配置し、390×844で各ボタンが均等幅に並ぶことを確認した。

### P2 — 見積もり0件のタスクで`SESSION 1/0`

見積もりポモドーロ数が0のタスクではセッション進捗を表示しないようにし、意味のない`1/0`表示を除去した。

### P3 — PWA capability meta warning

標準の`mobile-web-app-capable`を追加した。iOS互換用のApple metaは残している。再読み込み後のConsoleはReact DevToolsのINFOのみで、deprecated warningは再現しなかった。

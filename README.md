# FocusBoard

iPadのホーム画面に追加して、勉強中に表示しておける時計・ポモドーロPWAです。サーバーやアカウントは不要で、設定とタイマー状態は端末内だけに保存されます。

## 機能

- サムネイルから固定背景または自動切替を選べる、フェード式の背景スライドショー
- 端末内の任意画像を最大8枚までIndexedDBへ保存し、背景として選択・削除
- 午前・午後表記を省いた12時間表示／24時間表示、秒、サイズ、色、フォント、配置を変更できる時計
- 時計の配置付近の背景を解析し、読みやすい文字色とタイマーのアクセント色へ自動調整するオプション
- 背景画像の拡大率と表示位置を調整できる背景トリミング設定
- スカイ、ラベンダー、ミント、ピーチ、ローズのパステルテーマと、文字色・アクセント色を指定できるカスタムテーマ
- `Intl.DateTimeFormat`を使った日本語の日付・曜日
- 作業、短い休憩、長い休憩に対応したポモドーロ
- 実施中／休憩を分けられる通常カウントダウン・カウントアップ
- 開始後に円形へ縮小し、円周進捗を表示するドラッグ可能なフローティングタイマー
- 設定カード・円形タイマー・収納ボタンに共通で適用できる背景不透明度調整
- 開始前の設定カードも左端のコンパクトなボタンへ収納・復元
- `endAt`基準で、画面を閉じた後や再読み込み後もずれにくいタイマー
- iPadの縦向き・横向き、safe area、タッチ操作に対応した設定ドロワー
- 表示・背景・時計と日付・タイマー・ポモドーロ・アクセシビリティ・データ管理に分けた設定タブ。数値入力付きスライダー、3×3配置グリッド、自動保存状態、直前の変更の取り消しに対応
- 設定から全画面表示を切り替えられ、時計・日付・タイマーのサイズは「小さめ／標準／大きめ」で調整できる
- 追加背景の保存枚数・使用容量表示、削除、並べ替えに対応
- オフライン起動、設定初期化、タイマー削除、ローカルデータ削除、PWAキャッシュ削除
- 左端の「今日」ボタンから開ける、端末内保存のタスク管理（スマートリスト、プロジェクト、期限、リマインダー、繰り返し、サブタスク、メモ、検索）
- タスクから開始できるポモドーロ／通常タイマー、見積もりと集中実績、終了後の完了・継続操作
- 日・週・月、プロジェクト別、タスク別の集中レポートとセッション履歴
- タスク、プロジェクト、集中履歴のJSONバックアップ／検証付き復元

## 開発環境の準備

Node.js 20以降とnpmをインストールしてください。WindowsではPowerShellまたはWindows Terminalで次を実行します。

```bash
npm install
npm run dev
```

Viteが表示したURLをブラウザで開きます。同一ネットワークのiPadから確認するときは`npm run dev -- --host`を使用してください。

## テストとビルド

```bash
npm test
npm run build
npm run preview
```

成果物は`dist`に生成されます。通常のビルドは相対パスを使用するため、サブディレクトリからも配信できます。明示的な公開パスを使う場合は、Windows PowerShellで次のように指定します。

```powershell
$env:VITE_BASE_PATH="/repository-name/"
npm run build
```

## GitHub Pagesへの公開

1. このプロジェクトをGitHubリポジトリの`main`ブランチへpushします。
2. GitHubの **Settings → Pages** を開きます。
3. **Build and deployment** のSourceを **GitHub Actions** に設定します。
4. `main`へのpush、またはActions画面の手動実行で`.github/workflows/deploy.yml`がテストとビルドを行い、`dist`を公開します。
5. `https://<user>.github.io/<repository-name>/`へアクセスします。

Actionsではリポジトリ名から`VITE_BASE_PATH`を設定するため、Project PagesでもアセットとService Workerが正しい範囲に配置されます。ユーザーサイト用の`<user>.github.io`リポジトリでは、必要に応じてworkflowの値を`/`へ変更してください。

## iPadのホーム画面に追加

1. 公開URLをiPadのSafariで開きます。
2. 共有ボタンを押し、**ホーム画面に追加**を選びます。
3. 名前を確認して**追加**を押します。
4. 以後はホーム画面のFocusBoardアイコンからstandalone表示で起動できます。

初回読み込み後は主要ファイルがService Workerへキャッシュされ、オフラインでも起動できます。新しい版の反映にはオンライン状態で一度起動してください。

## 保存と初期化

設定は`focusboard:settings`、タイマーは`focusboard:timer`としてlocalStorageへ保存します。アップロードした背景画像は`focusboard-backgrounds`、タスク、プロジェクト、集中履歴は`focusboard-productivity`というIndexedDBへ端末内保存します。保存データは読み込み時に検証し、不正データや保存機能が利用できない場合も時計とタイマーは起動します。

開始前のタイマー設定は、右上の収納ボタンから開始後と同じ円形タイマーへ切り替えられます。セットした時間を保ったまま再生でき、リセットで中央の設定カードへ戻ります。円を指やApple Pencilでドラッグすると位置を変更でき、キーボード利用時はフォーカス後に矢印キーでも移動できます。Pauseでその場に一時停止し、Resetで中央の設定カードへ戻ります。

## タスクと集中記録

画面左下の **今日** を押すとタスク画面が開きます。タイトルだけですぐ追加でき、タスクを開くとプロジェクト、期限、リマインダー、繰り返し、見積もり、メモ、サブタスクを設定できます。タスク右端の開始ボタンからタイマーを始めると、完了または中断した集中時間がそのタスクへ記録されます。

上部の **レポート** では日・週・月の集中時間、プロジェクト比率、見積もり対実績、履歴を確認できます。**データ** ではタスク、プロジェクト、集中履歴をJSONへ書き出し、件数と形式を確認してから復元できます。同じIDはバックアップ側で上書きし、端末だけにあるデータは残します。背景画像と表示設定はこのバックアップに含まれません。

リマインダーはアプリを開いている間のアプリ内通知が基本です。対応ブラウザで通知を許可した場合だけシステム通知も使います。通知権限を許可しなくてもタスク機能は利用できます。

右下の設定ボタンにある **リセット / 削除** から、次を個別に実行できます。

- 設定だけを初期化
- タイマー状態だけを削除
- このアプリのローカルデータをすべて削除
- このPWAのキャッシュとService Workerを削除

「すべてのローカルデータ」には設定、タイマー、追加背景、タスク、プロジェクト、集中履歴が含まれます。必要なタスクデータは先にJSONへ書き出してください。

完全削除する場合は、先にローカルデータを削除し、iPadホーム画面のFocusBoardを長押しして **ブックマークを削除** または **Appを削除** を選びます。必要に応じてiPadの **設定 → Safari → 詳細 → Webサイトデータ** から公開サイトのデータも削除してください。Webアプリからホーム画面のアイコン自体を削除することはできません。

## プライバシー

タスク、集中履歴、背景画像を外部へ送信しません。ログイン、クラウド同期、外部サービス連携、他アプリのブロック機能は含みません。

## 比較した配置

- 全操作を2列に並べる案：削除と初期化が同じ優先度に見えるため不採用。
- 個別リセットを2列、削除操作を独立した縦グループにする案：意味ごとに視線を分けつつ、全消去の範囲を読めるため採用。

# 集中レポート・日別履歴 点検シート

対象: レポートを開く → 期間を選ぶ → セッション履歴を展開 → 日付別カードを確認・編集 → レポートへ戻る。

| # | 対象 | 意図 | 判定 | 根拠 | 直す方向 | 状態 |
|---:|---|---|---|---|---|---|
| 1 | レポートを開いた直後 | 集計と履歴の位置を知りたい | 問題なし | 期間切替と集計が先に見え、各セクションは見出しで区別される | | 済 |
| 2 | セッション履歴を見つける | 記録一覧へ移りたい | 身体操作 | 履歴はレポートの下部にあり、複数セクションをスクロールしてから開く必要がある | 現行レポート構成を維持（今回は妥協） | 済 |
| 3 | 履歴を展開する前 | 何件あるか確認したい | 問題なし | 見出し横に期間内の件数があり、開く前に量が分かる | | 済 |
| 4 | 履歴を展開した直後 | どの日に集中したか把握したい | 問題なし | 日付ごとの見出しと集中合計、完了回数が一覧される | | 済 |
| 5 | 同日複数セッション | その日の集中量を知りたい | 問題なし | 同じ日付のカードを一つの見出しに束ね、合計を表示する | | 済 |
| 6 | 0分の中断記録 | 中断記録を見分けたい | 問題なし | 中断状態が色と編集ボタンの読み上げ名で分かる。0分でも一覧に残る | | 済 |
| 7 | タスク名が長いカード | 記録の対象を確認したい | 情報欠落 | 幅が狭いと時刻列に幅を取られ、タスク名が一行で省略される | タスク名を折り返して表示 | 済 |
| 8 | タスク名がない記録 | 無題の記録だと理解したい | 問題なし | 「タスクなし」と表示され、時刻と実働時間も残る | | 済 |
| 9 | カードを選ぶ | 記録を編集したい | 問題なし | カード全体がボタンで、開始・終了時刻と状態が読み上げ名に含まれる | | 済 |
| 10 | 編集フォーム表示中 | 変更内容を保存・取消したい | 問題なし | 保存とキャンセルが同じフォーム内に並び、保存中は両操作を無効化する | | 済 |
| 11 | 保存失敗 | 変更が保存されなかったと知りたい | 問題なし | 保存失敗がフォーム内のアラートとして表示される | | 済 |
| 12 | 0件の期間 | 記録がないことを確かめたい | 問題なし | 履歴を開くと期間内に記録がない旨が表示される | | 済 |
| 13 | 50件を超える履歴 | 期間内の記録量を理解したい | 問題なし | 見出しに全件数を表示し、一覧の直前に最新50件を表示中と案内する | | 済 |
| 14 | 狭いスマートフォン幅 | 時刻と操作領域を保ちたい | 問題なし | 時刻列は固定幅で維持され、テキスト領域は縮み、見出しは折り返せる | | 済 |
| 15 | キーボードでカード操作 | 選択状態を把握したい | 問題なし | ボタンにフォーカス表示があり、選択中はaria-pressedが切り替わる | | 済 |
| 16 | 表示順と日付境界 | 新しい記録をすぐ見つけたい | 問題なし | 元の新しい順を保ち、開始時刻のローカル日付でグループ化する | | 済 |

全16件を判定。文言は「セッション履歴」「集中」「完了」「中断」「タスクなし」「休止」「集中記録を編集」を確認。記録種別と操作を具体的に表し、追加の説明文は不要。

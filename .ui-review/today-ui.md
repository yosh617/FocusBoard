# 今日一覧 点検シート

対象: タスク一覧から「今日」を開く → 今日の集計を確認 → タスクを追加・完了 → 完了済み一覧または今日の記録を見る。受信箱ビュー廃止後の期限なしタスクの統合も含む。

|---:|---|---|---|---|---|---|

| 3 | 進捗カード | 今日の作業量と実績を一度に把握したい | 問題なし | 見積もり、未完了数、集中時間、完了数が同じカードに並ぶ | | 済 |

## 期限なしタスクの統合

| # | 対象 | 意図 | 判定 | 根拠 | 直す方向 | 状態 |
|---:|---|---|---|---|---|---|
| 20 | 一覧ナビを開く | 期限なしのタスクをどこで見るか知りたい | 問題なし | ナビには「今日」「明日」「今後」「いつか」「完了済み」が残り、受信箱の独立項目はない | | 済 |
| 21 | 今日を選んで一覧を開く | 今日と未整理の作業をまとめて見たい | 問題なし | 今日/期限切れと、期限なし・通常 bucket のタスクが対象になる | | 済 |
| 22 | 今日一覧に明日・今後の期限付きタスクがある | 今日の対象を誤解なく把握したい | 問題なし | 明日・今後は引き続き個別ビューに残り、今日へ重複しない | | 済 |
| 23 | いつかを選ぶ | 後回しタスクを今日の作業と分けたい | 問題なし | `bucket: someday` かつ期限なしのタスクは今日に含まれない | | 済 |
| 24 | 今日と期限なしのタスクが両方ある | 期限状態で一覧を読み分けたい | 問題なし | 日付ありは上、日付なしは下の独立セクションに分かれ、見出しと件数が出る | | 済 |

| 26 | 今日の進捗を読む | 今日の予定量と未整理項目を混同したくない | 問題なし | 上部の未完了数と見積もりには期限なしタスクを含めず、一覧総件数には表示する | | 済 |

| 28 | 今日一覧の全件が0件 | 期限なしタスクの扱いを知りたい | 情報欠落 | 受信箱ビューをなくすと、期限なしのタスクが消えたと思う余地がある | 空状態に期限なしタスクも今日一覧で見られる旨を短く表示 | 済 |

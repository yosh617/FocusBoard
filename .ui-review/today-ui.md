# 今日一覧 点検シート

対象: タスク一覧から「今日」を開く → 今日の集計を確認 → タスクを追加・完了 → 完了済み一覧または今日の記録を見る。

| # | 対象 | 意図 | 判定 | 根拠 | 直す方向 | 状態 |
|---:|---|---|---|---|---|---|
| 1 | ナビから今日を選ぶ | 今日のタスクへ移りたい | 問題なし | 既存の「今日」ナビ操作で一覧を開き、戻る操作も維持される | | 済 |
| 2 | 今日画面の見出し | 表示中の一覧を確かめたい | 問題なし | タイトル「今日」が中央にあり、左の一覧ボタンで移動先を開ける | | 済 |
| 3 | 進捗カード | 今日の作業量と実績を一度に把握したい | 問題なし | 見積もり、未完了数、集中時間、完了数が同じカードに並ぶ | | 済 |
| 4 | 見積もり0分 | 見積もりがないと分かりたい | 問題なし | 0も「00:00」と表示し、値が空欄にならない | | 済 |
| 5 | 数時間の見積もり・実績 | 桁が増えても値を読みたい | 問題なし | 数字列は折り返さず、桁に応じて表示幅を使う | | 済 |
| 6 | タスク追加欄を見る | すぐに新しいタスクを入力したい | 問題なし | 集計カードの直後に入力欄があり、プラス操作と入力欄の両方が見える | | 済 |
| 7 | 空欄のまま追加する | 空のタスクを誤登録したくない | 問題なし | 入力前は追加ボタンが無効で、既存の必須入力動作も保つ | | 済 |
| 8 | 今日の未完了が0件 | 次に何をすればよいか知りたい | 問題なし | イラストと「上の入力欄から今日のタスクを追加できます。」が入力欄と一緒に表示される | | 済 |
| 9 | 今日の未完了0件、完了済みあり | 空状態と完了タスクの両方を見たい | 情報欠落 | 空状態を出す条件が完了タスク数に影響されず、完了済み開閉も同じ一覧内に残る | | 済 |
| 10 | 未完了タスクあり | 対象を選び完了または開始したい | 問題なし | 既存タスク行のチェックとタイマー操作をそのまま使える | | 済 |
| 11 | 完了済みの開閉 | 完了タスクを表示または隠したい | 問題なし | ボタン文言が表示状態に応じて切り替わり、件数とaria-expandedも示す | | 済 |
| 12 | 今日の記録が0件 | 記録がないことを確かめたい | 問題なし | 完了タスクの開閉後に「記録なし」と表示する | | 済 |
| 13 | 今日の記録がある | 対象・集中時間・結果・時刻を確かめたい | 問題なし | 各記録にタスク名、集中時間、完了／中断、終了時刻を表示する | | 済 |
| 14 | 記録のタスク名が長い | どのタスクの記録か判別したい | 問題なし | 記録カード内でタイトルを折り返し、省略せず表示する | | 済 |
| 15 | スマートフォン幅 | 4つの指標と追加操作を見失わず使いたい | 問題なし | 4列カードは最小幅向け文字サイズがあり、入力欄は全幅でタップ領域を保つ | | 済 |
| 16 | デスクトップ幅 | 内容が横に間延びしないよう見たい | 問題なし | ワークスペース既存の最大幅と左右余白の中にカードを配置する | | 済 |
| 17 | 画面の高さが小さい | 下の一覧や記録まで移動したい | 問題なし | 本文のスクロール領域を使い、固定高のページに閉じ込めない | | 済 |
| 18 | 保存機能が使えない | 追加できない理由を知りたい | 問題なし | 入力欄の近くに既存の保存不可案内を表示し、時計とタイマーは使える | | 済 |
| 19 | キーボードで入力・開閉 | フォーカス位置を把握して操作したい | 問題なし | 入力・ボタンをネイティブ要素で保ち、既存のフォーカス表示を使う | | 済 |

全19件を判定。文言は「今日の進捗」「見積もり時間」「未完了タスク」「集中時間」「完了タスク」「タスクなし」「記録なし」「完了済みタスクを表示／非表示」を確認した。
